# 8. Glossário

| Termo | Significado |
|---|---|
| **DOU** | Diário Oficial da União, o jornal oficial do governo federal, publicado pela Imprensa Nacional |
| **Seção 1** | Leis, decretos, portarias, resoluções e outros atos normativos (inclui as Resoluções-RE da ANVISA) |
| **Seção 2** | Atos de pessoal: nomeações, exonerações, aposentadorias |
| **Seção 3** | Contratos, editais, licitações, extratos e avisos |
| **Edição Extra** | Edição publicada fora do horário normal, quando há urgência |
| **Menção** | Uma publicação do DOU em que apareceu o CNPJ de uma empresa monitorada |
| **Raiz do CNPJ** | Os 8 primeiros dígitos do CNPJ (`XX.XXX.XXX`), iguais na matriz e em todas as filiais |
| **Rotina** | Uma busca programada: o que procurar, onde, quando e para quem avisar |
| **Rotina principal** | A rotina que procura os CNPJs de todas as empresas ativas. É mantida pelo próprio Registrale |
| **Origem** | De onde veio o cadastro da empresa: Manual, Google Sheets ou GestãoClick |
| **Sincronizar** | Trazer para o Registrale as empresas novas ou alteradas da planilha ou do ERP |
| **Concluída com pendências** | Busca em que alguma seção do dia ainda não pôde ser lida. O Registrale tenta de novo sozinho |
| **SMTP** | O servidor que envia e-mails. É preciso configurá-lo só se você quiser receber alertas por e-mail |
| **API do DOU** | O serviço de pesquisa do site da Imprensa Nacional (`in.gov.br`), usado para confirmar menções e obter o link da matéria |
| **PDF integral** | O arquivo completo de uma seção do DOU do dia, baixado de `pesquisa.in.gov.br` |
| **INLABS** | Serviço da Imprensa Nacional para download do DOU em lote. Não vem instalado no Registrale; quando ele falta, a busca usa o PDF integral e a API do DOU |
| **Bandeja do sistema** | A área de ícones ao lado do relógio do Windows, onde o Registrale fica enquanto roda |
| **Conta de serviço** | Um "usuário robô" do Google que o Registrale usa para ler a planilha |
