Manual de configuração: passo a passo para conectar sua planilha

Aprenda a habilitar a API no Google Cloud e compartilhar sua planilha privada

1 Google Cloud
Acesse o Google Cloud Console

Acesse console.cloud.google.com, faça login com sua conta Google e crie ou selecione um projeto existente.

2 Ativar API
Ative a Google Sheets API

Vá no menu lateral em APIs e Serviços > Biblioteca. Busque por Google Sheets API e clique no botão azul Ativar.

3 Credenciais
Crie uma conta de serviço

Em APIs e Serviços > Credenciais, clique em Criar Credenciais > Conta de Serviço. Dê um nome (ex: registrale-sync) e conclua.

4 Chave JSON
Baixe a Chave JSON

Clique na Conta de Serviço criada, vá na aba Chaves > Adicionar Chave > Criar nova chave > Escolha JSON e faça o download do arquivo.

5 Compartilhamento
Compartilhe sua planilha privada

Abra a planilha no Google Sheets, clique em Compartilhar e adicione o e-mail da Conta de Serviço com permissão de Leitor (Viewer).

6 Configuração
Preencha e sincronize

Cole a URL da planilha e o conteúdo do arquivo JSON abaixo, configure as colunas e clique em Testar conexão e Salvar.
